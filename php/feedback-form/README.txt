Домашняя работа 4.1 — Feedback Form

1. Распакуйте папку feedback-form в C:\xampp\htdocs\
2. Запустите Apache в XAMPP Control Panel.
3. Откройте http://localhost/feedback-form/
4. Проверьте заполнение формы и отправку на https://httpbin.org/post
5. Перейдите на вкладку «HTTP-заголовки» и проверьте вывод get_headers().

Для работы PHP не используйте Live Server VS Code — открывайте страницы через localhost.

Файлы:
index.php — форма POST
headers.php — вывод PHP get_headers()
style.css — оформление

Примечание: для отправки формы и запроса HTTP-заголовков требуется интернет.
